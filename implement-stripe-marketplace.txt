Stripe Marketplace Implementation Plan
This plan outlines the steps to implement the Stripe marketplace integration for the Biophlx platform, enabling trainer onboarding and secure checkout for workouts and services.

Proposed Changes
[Frontend - Onboarding]
[MODIFY] 
MonetizationSetup.js
Implement handleEnablePayouts function.
Invoke accounts.create Lambda to get a Stripe Account ID.
Store the Stripe Account ID in the 
Trainer
 table (via AppSync mutation).
Invoke accountlinks.create Lambda to get a Stripe onboarding URL.
Use WebBrowser.openBrowserAsync to redirect the trainer to the Stripe-hosted onboarding UI.
[Frontend - Marketplace]
[MODIFY] 
TrainerProfile.js
Implement handlePurchase function for workout products and services.
Invoke a Lambda function to create a Stripe Checkout Session or PaymentIntent, passing the trainer_id and price.
Configure the payment split (95% to trainer, 5% platform fee).
Use WebBrowser.openBrowserAsync to redirect the user to the Stripe Checkout UI.
[Backend - Webhooks (Context)]
Ensure the existing biophlx-stripe-handler Lambda correctly processes checkout.session.completed events.
Update the Client-Permissions table in DynamoDB to grant access to purchased content.
Verification Plan
